# CI1302 V5 语音控制闭环

## 数据链路

```text
语音模块 UART5
  AA 55 00 <01..30> FB
        ↓ STM32 校验、入队
USART1: VOICE,00,<ID>\r\n
        ↓ eggy_usart1_node
/stm32/voice_command
        ↓ eggy_voice_controller
现有命令中心 / Mission / 自动建图 / cmd_vel 仲裁
        ↓ 执行状态或结果
/stm32/voice_playback
        ↓ USART1: AA 55 FF <80..DA> FB
STM32 入队并转发 UART5 → 语音模块播报
```

STM32 不直接执行语音运动命令。所有动作仍进入 Linux 主控已有的安全状态、
任务状态机和速度仲裁链路。

## V5 命令分组

- `01`～`02`：急停、取消任务。
- `03`～`08`：低速短距离前后/横移/旋转微调。
- `09`～`0D`：系统、电池、模式、任务、环境查询。
- `0E`～`16`：相机、工作模式、建图、代价地图控制。
- `17`～`1D`：返航、点位 1～4、普通导航、巡检任务。
- `1E`～`22`：仪表识别、重试、重播结果。
- `23`～`28`：自动建图启动/暂停/继续/结束/状态与地图保存。
- `29`～`30`：AI 巡检开关、网络、重定位、任务暂停/继续、相机与安全查询。

完整 ID 到动作的唯一映射在
`src/eggy_bringup/src/eggy_bringup/voice_protocol.py` 中维护；被动播报范围固定为
`80`～`DA`。

## 安全约束

- 语音可以触发急停，但不能解除急停；解除必须由 Qt 或现场安全操作完成。
- 微动默认速度不超过 `0.16 m/s`、角速度不超过 `0.35 rad/s`，单次持续
  `0.45`～`0.55 s`，并持续发布到 `/cmd_vel/manual` 供仲裁器管理。
- `/eggy/emergency_stop` 或 `/base/flag_stop` 生效时立即停止微动。
- 单点、路线和巡检统一发布 `/eggy/mission/request`，不绕过现有 Mission runner。
- 仪表识别使用巡检 Mission 的搜索、对准、ROI 与 Kimi 闭环，不直接上传整幅带框画面。
- 语音命令无有效点位、地图、定位或传感器状态时只播报失败，不猜测执行。

## 点位配置

语音点位默认读取 `config/inspection_route.json`。示例占位 ID（`example_*`）会被
主动忽略，防止小车误导航到 `(0, 0)`。实际使用时至少配置：

```json
{
  "route": [
    {"id": "home", "frame_id": "map", "x": 1.2, "y": 0.5, "yaw": 0.0},
    {"id": "meter_1", "frame_id": "map", "x": 2.4, "y": 0.8, "yaw": 1.57,
     "expected_class": "water_meter"}
  ]
}
```

“返回起点”会匹配 `home`、`start`、`origin` 或 `起点`；“前往点位一～四”按
路线数组顺序选择。

## 实车验收

1. 检查 `/stm32/voice_command` 能收到 `{"func":"00","cmd":"..."}`。
2. 依次验证查询类、相机类和模式类命令，确认播报只在结果返回后发生。
3. 急停锁定时验证所有运动命令被拒绝，且语音无法解除急停。
4. 空旷区域验证六个微动命令，每次动作结束速度回零。
5. 配置真实点位后验证单点导航、任务链、巡检、暂停、继续和取消。
6. 验证自动建图的启动、暂停、继续、结束与地图保存结果。
7. 拔掉 USART1 或语音模块，确认 ROS 节点报告失败且不影响底盘安全停车。
